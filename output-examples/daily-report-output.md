# 日报输出样例

> 系统自动生成（展示版）

## 今日概览

- 今日完成 3 项任务
- 处理 1 个作业输入
- 处理 1 条调课记录
- 生成 1 份课程回顾
- 回写 1 篇日报

## 聚合结果

| 模块 | 状态 | 说明 |
|---|---|---|
| 作业状态 | 正常 | 已识别 4 项任务，其中 1 项高优先级 |
| 课表状态 | 已更新 | 调课记录已反映到回写课表中 |
| 运动记录 | 已统计 | 本月完成率维持在稳定区间 |
| 笔记沉淀 | 正常 | 新增 1 篇课程复盘笔记 |

## 系统建议

- 优先处理动态规划练习题
- 利用课表变更后的空档补写复盘摘要
- 保持轻输入，避免把内容层变成重管理工具

## 说明

这个样例用于展示执行层如何把多源状态整合成更有可读性的日级输出，而不是只做单点同步。
