# timetable-showcase

> ScholarFlow 执行层展示骨架仓库
>
> 用于展示多 Agent 学习系统的工作流编排、脚本职责、数据结构与自动回写链路。

---

## 仓库定位

这个仓库是执行层的 **公开展示版骨架**。

它保留了以下核心能力的说明方式：

- GitHub Actions 工作流如何编排
- Markdown 输入如何被解析为结构化数据
- JSON 状态如何驱动自动生成产物
- 双仓库如何完成“输入 -> 处理 -> 回写”的闭环

公开版不会包含真实隐私数据、真实密钥或真实用户轨迹。

---

## 核心模块

```text
timetable-showcase/
├── .github/workflows/      # 自动化工作流样例
├── data/                   # 脱敏后的 JSON 数据样例
├── scripts/                # 核心处理脚本骨架
├── docs/                   # 架构与事件流说明
├── output-examples/        # 自动生成产物样例
└── .env.example            # 环境变量占位说明
```

---

## 执行层职责

- 接收来自内容层的变更触发
- 解析 Markdown 中的轻量输入
- 更新结构化状态数据
- 生成课表、日报、周报或研究产物
- 将结果回写到内容层仓库

---

## 说明

本仓库中的工作流名称、脚本名称和数据格式接近真实系统，但仓库名、样例数据、时间、地点与输出内容均已脱敏，仅用于展示系统设计与工程实现方式。
