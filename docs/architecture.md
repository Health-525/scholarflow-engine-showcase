# 架构说明

执行层承担的是系统中所有偏“机器侧”的工作：接收输入、解析内容、更新状态、生成产物，并把结果回到内容层仓库。

## 模块图

```mermaid
flowchart LR
    A[内容层 Markdown 输入] --> B[脚本解析层]
    B --> C[JSON 状态层]
    C --> D[Markdown 产物层]
    D --> E[内容层回写结果]
```

## 主要职责

- 接收内容层触发事件
- 解析 Markdown 输入
- 更新 JSON 状态
- 生成可读产物
- 回写到内容层仓库

## 为什么独立成仓库

- 降低内容与逻辑耦合
- 便于维护工作流与脚本
- 便于展示系统能力，而不暴露私人内容
- 更适合把“输入界面”和“执行中枢”分别讲清楚
