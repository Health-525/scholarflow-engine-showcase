# 隐私说明

这是一个公开展示版执行层仓库，用于展示工程结构、样例数据与最小可验证链路。

## 有意移除的内容

- 真实 token、Cookie、API key、webhook
- 真实课程、真实地点、真实时间轨迹
- 连续长期状态与生产环境依赖
- 私有仓库地址和完整写回权限配置

## 当前仍然保留的内容

- GitHub Actions 的组织方式
- 样例 JSON 状态结构
- 一条本地可验证的 Markdown 生成链路
- 其余 workflow 的职责边界与分工方式

## 如何理解这些样例

这些样例属于“真实工程结构 + 脱敏内容”。

也就是说：
- 目录组织、脚本边界和输入输出形态尽量接近真实系统
- 具体课程、地点、日期、样例数量经过替换
- 部分 workflow 与脚本保留为 `showcase-only`，用于说明边界，而非公开完整私有实现
